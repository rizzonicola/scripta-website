Informativa privacy

Ultimo aggiornamento: 1 novembre 2026

Questa informativa descrive come vengono trattati i dati personali quando visiti scripta.poppi.cc e quando usi la web app app.scripta.poppi.cc. Le app desktop e mobile di Scripta sono local-first e non inviano dati a noi.

1. Titolare del trattamento

Il titolare del trattamento è Nicola Rizzo, contattabile all'indirizzo info@poppi.cc. Scripta è un progetto personale e open source; non è nominato un responsabile della protezione dei dati (DPO), perché non ricorrono i presupposti previsti dall'art. 37 GDPR.

2. Quali dati trattiamo

2.1 Dati di navigazione e sicurezza

Il sito è distribuito tramite Cloudflare. Come ogni CDN, Cloudflare può trattare dati tecnici necessari a consegnare le pagine e a proteggere il servizio: indirizzo IP, User-Agent, URL richiesto, data e ora, codice di risposta e informazioni di sicurezza. Questi dati non sono usati da noi per profilare i visitatori.

Non usiamo strumenti di analytics, pixel pubblicitari, social plugin o profilazione. Non vendiamo dati personali.

2.2 Storage locale del sito

Il sito non imposta cookie propri. Usa la memoria locale del browser (localStorage) per ricordare le tue scelte:

ChiaveFinalitàTipoDurata
sc_langLingua sceltaNecessarioFino alla cancellazione
sc_themeTema scuro, chiaro o alto contrastoNecessarioFino alla cancellazione
sc_consentMemorizza la scelta fatta nel bannerNecessarioFino alla cancellazione
sc_optPreferenza sulla cache facoltativaNecessarioFino alla cancellazione
sc_cacheCache delle informazioni sulle releaseFacoltativo, solo con consenso1 ora

Puoi cancellare questi dati in qualsiasi momento dalle impostazioni del browser. La cancellazione non compromette l'uso del sito.

2.3 Informazioni sulle release

La pagina di download legge il file /releases.json dallo stesso sito. Solo se questo file non è disponibile, il browser interroga l'API pubblica di GitHub: in quel caso GitHub riceve il tuo indirizzo IP e i dati tecnici della richiesta. Lo stesso vale quando apri un link verso GitHub.

2.4 Web app

La web app app.scripta.poppi.cc è local-first. Le note, le cartelle e le impostazioni vengono salvate nel browser del tuo dispositivo (SQLite in WebAssembly con persistenza in IndexedDB e localStorage). Questi dati non vengono inviati a noi.

Se attivi la sincronizzazione, la web app invia note e credenziali al server che configuri tu. Non gestiamo un server di sincronizzazione centrale: il titolare di quel server è il soggetto che lo mette a disposizione. La web app non include analytics né telemetria.

Il service worker della web app memorizza nella cache del browser gli asset necessari al funzionamento offline. Puoi rimuovere app e dati dalla schermata delle impostazioni del browser o cancellando i dati del sito. Esporta le note in ZIP o Markdown prima di farlo.

2.5 Email

Se scrivi a info@poppi.cc, trattiamo il tuo indirizzo email e il contenuto del messaggio per rispondere alla richiesta. Non usiamo l'indirizzo per newsletter o marketing.

3. Base giuridica

  • Legittimo interesse (art. 6.1.f GDPR): sicurezza del sito, prevenzione di abusi e funzionamento tecnico.
  • Consenso (art. 6.1.a GDPR): cache facoltativa delle release. Puoi revocarlo dal banner o dalle impostazioni del sito.
  • Esecuzione di un contratto o misure precontrattuali (art. 6.1.b GDPR) e/o legittimo interesse: risposta alle email che ci invii.

4. Destinatari e trasferimenti

I dati possono essere trattati da:

  • Cloudflare, Inc. — CDN, DNS e protezione del sito. Cloudflare può trattare dati anche fuori dall'UE; il trasferimento avviene sulla base di clausole contrattuali standard e/o dell'adesione al Data Privacy Framework UE-USA, ove applicabile.
  • GitHub, Inc. — solo per le richieste all'API delle release e per i link esterni. GitHub può trattare dati negli USA; anche in questo caso valgono clausole contrattuali standard e/o il Data Privacy Framework, ove applicabile.

Non comunichiamo dati a inserzionisti, broker di dati o altre terze parti per finalità di marketing.

5. Conservazione

I log tecnici e di sicurezza sono conservati da Cloudflare secondo la configurazione del servizio e per il tempo necessario a garantire sicurezza e continuità. Lo storage locale resta nel tuo browser fino alla cancellazione. Le email vengono conservate per il tempo necessario a gestire la richiesta e poi cancellate, salvo obblighi di legge.

6. I tuoi diritti

Puoi esercitare i diritti previsti dagli artt. 15–22 GDPR: accesso, rettifica, cancellazione, limitazione, opposizione, portabilità e revoca del consenso. Scrivi a info@poppi.cc; risponderemo entro i termini previsti dalla legge.

Se ritieni che il trattamento violi il GDPR, puoi proporre reclamo al Garante per la protezione dei dati personali o all'autorità di controllo del tuo Paese.

7. Cookie

Questo sito non usa cookie di profilazione. Cloudflare può impostare cookie tecnici di sicurezza (ad esempio __cf_bm) quando le funzioni di protezione bot sono attive; sono necessari alla sicurezza del servizio e non richiedono consenso. Il banner che vedi serve a raccogliere il consenso per la cache facoltativa delle release e a informarti sull'uso dello storage locale.

8. Minori

Il sito e la web app non sono destinati a bambini di età inferiore a 14 anni. Non raccogliamo consapevolmente dati di minori. Se ritieni che un minore ci abbia inviato dati, scrivici e li cancelleremo.

10. Modifiche

Possiamo aggiornare questa informativa per riflettere cambiamenti tecnici o normativi. La versione corrente è sempre pubblicata su questa pagina, con la data di ultimo aggiornamento in alto.

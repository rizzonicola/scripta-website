Editor di note open source e local-first. Markdown puro, ricerca istantanea, sincronizzazione self-hosted. Per tutti i tuoi dispositivi, anche nel browser.

Apri la Web App →

Scripta è un'app di note Markdown open source, pensata per chi vuole scrivere senza vincoli: nessun account obbligatorio, nessun cloud imposto. È local-first: le note vivono sul tuo dispositivo, con ricerca istantanea via SQLite e sincronizzazione opzionale verso un server che scegli tu. Disponibile gratuitamente per Android, iOS, macOS, Windows, Linux e Web (PWA).

Scripta nel browser

Prova Scripta senza installare nulla. La web app usa WebAssembly sui browser moderni, salva le note in IndexedDB sul tuo dispositivo e funziona offline dopo il primo caricamento. Installabile come PWA, senza account obbligatorio; le note nel browser sono separate da quelle delle app, quindi usa export/import o la sincronizzazione opzionale.

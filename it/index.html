Editor di note open source e local-first. Markdown puro, ricerca istantanea, sincronizzazione self-hosted. Per tutti i tuoi dispositivi.

Scripta è un'app di note Markdown open source, pensata per chi vuole scrivere senza vincoli: nessun account obbligatorio, nessun cloud imposto. È local-first: le note vivono sul tuo dispositivo, con ricerca istantanea via SQLite e sincronizzazione opzionale verso un server che scegli tu. Disponibile gratuitamente per Android, iOS, macOS, Windows e Linux.

Pensata per scrivere

Editor Markdown

Sintassi evidenziata, toolbar intelligente e vista di lettura istantanea.

Local-first

Avvio immediato e ricerca rapidissima con SQLite WAL. Funziona offline.

Sincronizzazione

Sync asincrona con backend self-hosted, risoluzione Last-Write-Wins.

Cartelle annidate

Preferiti, note fissate e drag & drop.

Tuoi dati

Import/export ZIP o file Markdown. Nessun lock-in.

Multipiattaforma

Android, iOS, macOS, Windows e Linux.

Privacy e cookie

Questo sito usa solo cookie/storage strettamente necessari (lingua e tema scelti). Nessuna profilazione, nessuna vendita di dati a terzi.

Il traffico può transitare da Cloudflare (anche via Cloudflare Tunnel), che tratta indirizzo IP di origine, User-Agent e log di sicurezza per mitigare attacchi DDoS. Le informazioni sulle release sono richieste direttamente all'API pubblica di GitHub dal tuo browser (GitHub riceve il tuo IP).

Base giuridica: legittimo interesse (art. 6.1.f GDPR) per sicurezza e funzionamento; consenso per il resto. Puoi cambiare idea da Impostazioni → Privacy. L'app Scripta è local-first: le note restano sul tuo dispositivo o sul tuo server.

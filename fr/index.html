Prise de notes open source et local-first. Markdown pur, recherche instantanée, synchronisation auto-hébergée. Sur tous vos appareils.

Scripta est une application de notes Markdown open source, pensée pour écrire sans contrainte : aucun compte obligatoire, aucun cloud imposé. Elle est local-first : vos notes restent sur votre appareil, avec une recherche instantanée via SQLite et une synchronisation optionnelle vers un serveur que vous choisissez. Gratuite pour Android, iOS, macOS, Windows et Linux.

Conçue pour écrire

Éditeur Markdown

Coloration syntaxique, barre d'outils intelligente et lecture instantanée.

Local-first

Démarrage immédiat et recherche ultra-rapide (SQLite WAL). Hors ligne.

Synchronisation

Sync asynchrone avec serveurs auto-hébergés, résolution Last-Write-Wins.

Dossiers imbriqués

Favoris, notes épinglées et glisser-déposer.

Vos données

Import/export ZIP ou Markdown. Aucun verrouillage.

Multiplateforme

Android, iOS, macOS, Windows et Linux.
